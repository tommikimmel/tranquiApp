# Sprints

No usamos Scrum formal: los sprints son solo una forma de dividir y agrupar las tareas. Cada
sprint tiene un archivo `sprint-NN.md` basado en [`_plantilla.md`](_plantilla.md).

- Cada tarea del sprint corresponde a una rama y un PR (`docs/flujo/git.md`).
- Los PRs del sprint llevan la etiqueta `sprint-NN`.
- Al cerrar el sprint se hace el release `develop → main` (`docs/flujo/releases.md`) y lo que
  quedó pendiente pasa al sprint siguiente.
