# Tranqui App

Plataforma para consultorios de salud mental: buscador de psicólogos y psiquiatras, reserva y pago
de turnos, telemedicina, chat y gestión del consultorio. En producción en
https://tranquisalud.com.

- **Cómo trabajamos (personas y agentes de IA):** [AGENTS.md](AGENTS.md)
- **Documentación:** [docs/](docs/README.md)
- **Versiones:** [CHANGELOG.md](CHANGELOG.md)
- **Levantar en local:** [docs/entornos/local.md](docs/entornos/local.md)

Ramas: `main` es producción y `develop` el desarrollo en curso. Todo cambio entra por Pull Request
(ver [docs/flujo/git.md](docs/flujo/git.md)).
